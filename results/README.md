## Как оценивали

Эталон — атрибуты фида М.Видео, приведённые к канону (`core_gold`); заглушки («другой», «000») — пропуск, а не
ошибка. Разбиение по группам «бренд + модель», дубли описаний — в одной части. Словари строятся только по train,
калибровка и пороги — по valid. Здесь — только отложенные части: **test** (95 971 карточка известных категорий) и
**holdout_category** (68 476 карточек категорий, целиком не участвовавших в подборе, — «новые категории»).

P и R — по значениям со статусом `accepted` (что попадает в каталог без проверки); R — от всех пар с эталоном.
`_any` — по всем найденным значениям, включая отправленные на проверку.

## Что видно

- **Калибровка — главный рост:** F1 с 33,0% до 51,8% при той же точности ~90%. Порог по атрибуту подобран так,
  чтобы точность принятых значений на valid была ≥ 90%.
- **Где точность не набрана, значение не принимается вовсе.** У цвета, веса, глубины и процессора найденные значения
  верны в 23–80% случаев, и калибровка отправляет их на проверку: в каталог не попадает ни одного. Это плата
  за запрет на выдумывание, а не ошибка; поднимать нужно точность извлечения (план — ниже).
- **Парсер и retrieval на офферах почти ничего не добавляют**: блоки «ключ: значение» есть у 36–38% карточек без
  оффера и почти не встречаются у офферов, а эталон есть только у офферов. Их вклад виден на карточках без оффера,
  где оценить его можно только ручной разметкой.
- **Новые категории — слабое место:** F1 34,3% против 61,5%. Схема обязательных атрибутов у новой категории
  строится по её же заполненности, а словари — только по известным категориям.
- **Шаг 0 со скрытой категорией:** 92,7% карточек получают категорию, верную — 54,9%. Это test и holdout вместе:
  категории holdout классификатор не видел. Для известных категорий базлайн по заголовку в EDA — 93,5%.
- **Продавцы:** у самых маленьких (1–10 товаров) F1 44,9% против 57,2% у крупнейших. В группе 1k–10k точность
  76,5% против 93–98% у соседних — причину ещё не разбирали.
