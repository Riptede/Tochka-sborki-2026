# attrex: атрибуты товаров из текста карточки

Решение команды TushavinClub по кейсу М.Видео. Пайплайн читает карточку товара (заголовок, описание, атрибуты
продавца), извлекает обязательные характеристики, приводит их к каноническому виду и для каждого значения выдаёт
уверенность. Каскад: правила и словари → retrieval к справочнику → LLM для остатка → ручная проверка.

Статус: готов разведочный анализ (`notebooks/01_eda.ipynb`) и прототип интерфейса модератора
(`apps/review_prototype/index.html`). Пайплайн в разработке, план — в `CLAUDE.md`.

## Установка

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```
uv sync --extra eda
```

Файлы организатора положите в `data/raw/`:

```
data/raw/skus.pkl
data/raw/sku_desc.parquet
data/raw/query_clicks.parquet
```

## Запуск

```
uv run pytest                                              # проверка окружения и конфигов
uv run jupyter nbconvert --to notebook --execute --inplace notebooks/01_eda.ipynb
```

Первый прогон EDA занимает около 15 минут. При 16 ГБ памяти и больше задайте `EDA_FAST_PICKLE=1`, чтобы `skus.pkl`
загрузился целиком за минуту.

## Структура

- `configs/` — реестр атрибутов и параметры пайплайна
- `src/attrex/` — код пайплайна по блокам (БД, нормализация, LLM, метрики, ручная проверка)
- `notebooks/` — EDA
- `apps/review_prototype/` — прототип интерфейса модератора, открывается в браузере
- `docs/checkpoints/` — материалы чекпоинтов
