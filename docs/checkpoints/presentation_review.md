## Что добавить

1. **Итог.** test + holdout_category: P 91,2%, R 39,5%, F1 55,1%, R_text 68,8%. Известные категории (test) —
   P 96,7%, F1 62,5%, R_text 82,0%; новые (holdout_category) — P 79,6%, F1 42,4%. В тексте карточек лежит только 57%
   эталона: выше без выдумки не подняться.
2. **Вклад шагов (вместо слайда 10).** Без калибровки F1 33,1%, с калибровкой 55,1% — главный рост. Правила дают
   99,5% принятых значений; парсер и retrieval на офферах почти ничего не добавляют: блоки «ключ: значение» у офферов
   редкие, retrieval выключен. Объяснить честно, а не прятать.
3. **LLM и стоимость.** Только цвет — по замеру на valid остальные атрибуты не прошли порог точности. На test
   (4 000 карточек): F1 57,8% → 58,6%, F1 по трафику 37,7% → 39,8%, 1,99 ₽ на 1 000 карточек — в 8 раз дешевле
   первого варианта (все атрибуты смартфонов и ноутбуков, 15,4 ₽). Точность цветов от LLM — 86% при цели 90%,
   поэтому в итоговом прогоне LLM выключен. Весь каталог — 1,48 млн карточек за ≈18 минут на 3 ядрах CPU, 0 ₽.
4. **Покрытие каталога «до / после».** Офферы: фид 94,8% → 95,0%. Карточки без оффера (63% каталога): фида нет,
   каскад принимает 38,0% обязательных полей. Все карточки: 36,5% → 59,9%.
5. **Атрибуты.** Сильные: бренд F1 83%, модель 81%, объём памяти 87%, высота 54%, ширина 44% (после размеров из
   описания: было 32% и 27%). Слабые и почему: цвет, материал, вес — в тексте лежит 28%, 19% и 5% эталона.
6. **Срезы.** Хвост из 2 279 категорий вне топ-20 по трафику — F1 64,0%; новые категории — 42,4%. Продавцы:
   1–10 товаров — F1 45,3%, крупнейшие — 63,5%; у группы 1k–10k точность 77%.
7. **Сценарий модератора.** Скриншот `review.html` (`demo.py` → `outputs/demo/demo/review.html`): цитата
   подсвечена, кнопки «Принять / Исправить / Нет значения», клавиши A / F / X; решения → синонимы в словарь.
   Приоритет очереди — клики × вес атрибута × (1 − уверенность).
8. **Как пользоваться.** Демо без данных за 10 с (`demo.py`); своя карточка с причиной статуса и JSON для сервиса
   (`demo.py --title … --json`); полный запуск по README.
9. **Ограничения и что дальше.** Новые категории (точность 80%); точность цвета от LLM 86% < 90%; шум эталона
   (вес и габариты в фиде расходятся с текстом); на карточках без оффера точность не измерена — нужна ручная
   разметка через интерфейс модератора.
