# Разведочный анализ данных (EDA)

Полный анализ с кодом, таблицами и графиками — ноутбук [`notebooks/01_eda.ipynb`](../../notebooks/01_eda.ipynb).
Здесь — та же тетрадь в Markdown для чтения без Jupyter: [`01_eda.md`](01_eda.md), графики — в
[`01_eda_files/`](01_eda_files/). Имена продавцов-ИП в выводах заменены номерами.

## Главное

- **Разметка уже есть в фиде.** У атрибута два слоя: `Имя_search` — сырое значение, которое извлекаем, и фасет —
  канон для фильтров, к которому нормализуем. 18% фасетов цвета — заглушки («другой», «другие цвета»): это пропуск,
  а не значение.
- **79% карточек без категории.** 936 тыс. из 1,18 млн описаний не имеют оффера в фиде. Категорию берём из кликов
  (`seo_id` совпадает с категорией в 97%, но есть у 6%) или по заголовку (базлайн 93,5%).
- **Длинный хвост.** 3,6 тыс. листовых категорий, медиана — 10 офферов; больше всего матрасов, чехлов и штор.
  Схема обязательных атрибутов выводится автоматически, мелкие категории наследуют её от родителя.
- **Не всё есть в тексте.** Бренд и память — в заголовке, процессор и накопитель — в описании, цвет часто только
  через синонимы (`Titanium Grey` → серый). У восстановленных и уценённых товаров диагонали и батареи нет в тексте
  совсем: такие значения не извлекаются, а не выдумываются.
- **Единицы.** Единица часто лежит в `@unit`, а не в значении; 79 атрибутов встречаются в разных единицах; фасеты
  чисел — корзины («3000–5000 мАч»), а не значения.
- **Трафик.** Ищут прежде всего по бренду, затем по ключевому атрибуту категории (диагональ, тип, серия, память):
  отсюда веса для F1 с учётом трафика.
- **Разбиение.** Дубли описаний (22%) и варианты одной модели — в одной части; отдельные категории отложены целиком
  для проверки на новых.

Как эти выводы превратились в решение — таблица «В данных / задаче → Мы делаем» в конце [`01_eda.md`](01_eda.md).

## Воспроизвести

Нужны файлы организатора в `data/raw/` (README, «Полный запуск»), ≈15 минут и 3 ГБ памяти:

```
uv sync --extra eda
uv run jupyter nbconvert --to notebook --execute --inplace notebooks/01_eda.ipynb
uv run jupyter nbconvert --to markdown notebooks/01_eda.ipynb --output-dir docs/eda --output 01_eda
```
